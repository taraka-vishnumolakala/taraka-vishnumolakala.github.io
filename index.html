Sr. Cybersecurity Engineer, Security Architecture · Workday, Inc

I started my career as a software engineer, which gave me a deep appreciation for the decisions developers make under pressure — and the oversights those decisions can leave behind. That perspective shaped how I approach security: not as an external audit, but as someone who understands where systems are most likely to fail and how those gaps translate into real attack surface.

Today I specialize in application & API security, cloud infrastructure hardening, threat modeling, and offensive security — including pentesting and red teaming that feeds actionable findings back into the engineering process. I also focus on AI/ML risk: assessing model attack surfaces and designing controls for systems whose behavior is inherently non-deterministic.

I care about building security cultures that last — running security champions programs, embedding security awareness into engineering workflows, and empowering developers to own security as a natural part of how they build.
