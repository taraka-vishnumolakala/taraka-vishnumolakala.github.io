You do not need advanced mathematics to begin learning machine learning. Start
with a small idea, change its inputs, and watch what happens. The notation comes
after the intuition.

## Start here

### [1. Gradient Descent](/knowledge/ml-engineering/math-foundations/gradient-descent/)

See how a model improves a parameter by following the local slope of its error.
The interactive loss curve lets you take each optimization step and test what
happens when the learning rate is too small or too large.

### [2. Sigmoid & ReLU](/knowledge/ml-engineering/math-foundations/sigmoid-and-relu/)

See how two activation functions transform the number produced by a neuron.
The interactive graph lets you compare sigmoid’s 0-to-1 curve with ReLU’s rule
for blocking negative values and passing positive values through.

### [3. Softmax](/knowledge/ml-engineering/math-foundations/softmax/)

See how a model converts several competing class scores into probability shares
that add up to 100%. The interactive controls show how scores and temperature
change the distribution.

### [4. Cross-Entropy Loss](/knowledge/ml-engineering/math-foundations/cross-entropy-loss/)

See how training grades the probability assigned to the correct class. The
interactive curve makes the penalty for a confident mistake easy to compare
with the small penalty for a strong correct prediction.

### [5. Linear Regression (Forward Pass)](/knowledge/ml-engineering/math-foundations/linear-regression-forward/)

Follow a numerical prediction through its simplest complete path: multiply the
input by a weight, add a bias, and read the result. The interactive line shows
the separate effect of the input, weight, and bias.

### [6. Linear Regression (Training)](/knowledge/ml-engineering/math-foundations/linear-regression-training/)

Watch a line learn its weight and bias from completed investigations. The
interactive trainer shows the forward pass, mean squared error, gradients, and
parameter updates working as one repeated loop.

## How to use these lessons

1. Read the plain-language example first.
2. Move every control in the interactive lab—even to values that look wrong.
3. Predict what will happen before checking the result.
4. Open the self-check answers only after explaining your answer aloud.

Each lesson stands on its own, but following them in order will make later
concepts easier to understand.
