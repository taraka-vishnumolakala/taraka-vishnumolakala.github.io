Sr. Cybersecurity Engineer, Security Architecture · Workday, Inc

I started my career as a software engineer. That experience gave me a deep appreciation for the decisions developers make under pressure, along with the oversights those decisions can leave behind. It shaped how I approach security today. Rather than looking for known vulnerability classes or following a rigid framework, I work as someone who understands where systems are most likely to fail and how those gaps translate into real attack surface.

Today I specialize in Agentic Security and the stack that powers it, from protocols like MCP, A2A, and A2UI to agent identity and agent-building frameworks such as LangGraph and the Claude Agent SDK. This builds on my prior experience in application and API security, cloud infrastructure hardening, threat modeling, and offensive security, with findings flowing back into the development lifecycle through a shift left approach.

I care about building security cultures that stick with developers. That means running security champions programs, embedding security into engineering workflows, and giving engineering and security leadership actionable feedback on how the teams are performing.
